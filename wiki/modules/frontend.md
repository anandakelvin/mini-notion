# Frontend

React 19 + Vite, with the React Compiler (Babel preset). Routing is TanStack Router with file-based routes in `src/routes/`; `routeTree.gen.ts` is generated by the Vite plugin. UI parts are shadcn/ui copies in `src/components/ui/`.

## Routes

| Route | File | What it shows |
|---|---|---|
| (root) | `__root.tsx` | Checks auth on start. Redirects to `/auth` if not logged in. |
| `/auth` | `auth.tsx` | `LoginForm` (login and register). Redirects to `/notes` once logged in. |
| `/notes` | `notes/index.tsx` | The user's email, note count, list of notes, "New Note" dialog, delete button. |
| `/notes/$noteId` | `notes/$noteId.tsx` | Title input and BlockNote editor with auto-save and live sync. |
| any other path | `main.tsx` (`defaultNotFoundComponent`) | Redirects to `/notes`. |

## Data hooks

`useFetch` (`hooks/core/use-fetch.ts`) wraps axios with `withCredentials: true`. It cancels the previous in-flight request, auto-runs on mount unless `manual: true`, and resets the auth store on 401. The note hooks (`use-fetch-notes`, `use-fetch-note`, `use-create-note`, `use-update-note`, `use-delete-note`) are thin wrappers around it. Base URL: `API_URL` from `lib/utils.ts`.

## Editor (`$noteId.tsx`)

- BlockNote with a reduced schema: paragraph, checklist, image, code ([ADR-011](../architecture/decisions.md#adr-011-editor-limited-to-four-block-types)). Rendered with `@blocknote/shadcn`.
- The note is loaded once (`hasInitialized`), then the editor owns the content.
- **Auto-save**: any title or editor change restarts a 1 s timer, then `PUT /api/notes/:id` with the title, the whole block tree and `lastSavedAtRef` as `updatedAt`. A 409 shows a "conflict, please refresh" toast ([ADR-004](../architecture/decisions.md#adr-004-optimistic-concurrency-on-updated_at)).
- The header shows "Saving..." or "Saved".
- Live sync and remote cursors: see [realtime](realtime.md).

## Note on `@tiptap` versions

The root `package.json` pins `@tiptap/core` and `@tiptap/react` to `3.22.5` with `pnpm.overrides`. The frontend imports `Extension` from `@tiptap/core` directly for the cursor extension.
