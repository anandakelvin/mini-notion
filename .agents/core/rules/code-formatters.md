# Code formatters & static analysis (portable policy)

> **Portable.** Run this project's formatters, linters, and static analysis tools before finalizing changes, so the codebase stays consistent — that principle holds regardless of stack. This project's exact commands live in `.agents/project/code-formatters.md`, which is *not* portable — write an equivalent for whatever toolchain a new project uses (ESLint/Prettier, Black/Ruff, gofmt, rustfmt, whatever applies).
